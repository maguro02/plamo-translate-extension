# PLaMo 翻訳（ローカル）

選択したテキストやページ全体を、Chrome の中で動く翻訳モデル PLaMo 3 Translate で翻訳する Chrome 拡張です。翻訳する文章は外部に送りません。

## 動作環境

- Google Chrome 124 以降（Mac / Windows）
- 空き容量 1GB 以上（標準の 0.8B モデルの場合。2B モデルは 2GB 以上）
- GPU（WebGPU）が使える PC を推奨します。使えない場合は CPU で動き、翻訳に時間がかかります。

## 導入

1. zip を展開します。`plamo-translate-extension` フォルダができます。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した `plamo-translate-extension` フォルダを選びます。
4. 開いていたタブは、再読み込みすると「訳」ボタンが使えるようになります。

展開したフォルダは削除・移動しないでください。拡張が動かなくなります。

## 使い方

- **選択範囲の翻訳**: テキストを選択すると、カーソル位置に「訳」ボタンが出ます。押すと翻訳ウインドウが開きます。右クリックメニューの「PLaMo で翻訳」や `Alt+Shift+T`（Mac は `Option+Shift+T`）でも翻訳できます。
- **ページ全体の翻訳**: ページの右クリックメニューの「このページを PLaMo で翻訳」か `Alt+Shift+P`（Mac は `Option+Shift+P`）。もう一度実行するか、右下の「元に戻す」で元に戻ります。
- **翻訳履歴**: 翻訳ウインドウの「履歴」か、ページの右クリックメニューの「PLaMo 翻訳の履歴」。直近50件を保存します。
- **設定**: ツールバーの拡張アイコン、またはページの右クリックメニューの「PLaMo 翻訳の設定」。

日本語が多い文章は英語に、それ以外は日本語に訳します。翻訳ウインドウのボタンで逆方向に訳し直せます。訳文は生成しながら少しずつ表示します。

## 初回の翻訳

最初に翻訳したときに、翻訳モデル（約0.6GB）を Hugging Face からダウンロードします。進み具合は翻訳ウインドウに表示されます。ダウンロードしたモデルは Chrome の中に保存され、次回からはオフラインでも翻訳できます。

Chrome を起動して最初の翻訳では、モデルの読み込みに数秒かかります。

## 設定

| 項目 | 内容 |
|---|---|
| 翻訳エンジン | 自動（標準。翻訳サーバーが起動していればそれを、なければブラウザ内 0.8B）/ ブラウザ内 0.8B / ブラウザ内 2B（高品質・約1.8GB・遅い）/ 翻訳サーバーだけ |
| 翻訳サーバー | 起動・停止のボタン、翻訳モデルの新しい版があるときの「更新」ボタン、「翻訳するときに自動で起動する」（同梱の翻訳サーバーを1回起動して登録したあとに使えます） |
| 日本語に訳すときの文体 | です・ます調（標準）/ だ・である調 / 指定しない |
| ページ全体を翻訳したときの表示 | 原文の下に訳文を表示（対訳）/ 原文を訳文に置き換え |
| 「訳」ボタン | 選択し終えたときにボタンを表示するかどうか |

ダウンロードしたモデルは、設定画面の「ダウンロードしたモデルを削除」で削除できます。

## 使えないページ

`chrome://` で始まるページ、Chrome ウェブストア、Chrome の PDF ビューアーでは使えません。

## 困ったとき

- **翻訳が遅い**: 設定画面で「WebGPU を使えないため CPU で動作します」と出ている場合は、GPU が使えていません。Chrome の設定で「グラフィック アクセラレーションが使用可能な場合は使用する」がオンになっているか確認してください。
- **モデルをダウンロードできない**: `huggingface.co` に接続できるネットワークか確認してください。
- **「訳」ボタンが出ない**: タブを再読み込みしてください。設定画面でボタンの表示がオフになっていないかも確認してください。
