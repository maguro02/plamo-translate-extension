# PLaMo 翻訳

選択したテキストやページ全体を、翻訳モデル PLaMo 3 Translate で翻訳する Chrome 拡張と、翻訳を速くするための翻訳サーバーのセットです。翻訳は自分の PC の中で行い、文章を外部に送りません。

## 中身

| フォルダ | 内容 |
|---|---|
| `extension` | Chrome 拡張。これだけでも翻訳できます（ブラウザ内で翻訳） |
| `server-windows` | Windows 用の翻訳サーバー。起動すると翻訳が速く、訳の品質も上がります |
| `server-mac` | Mac（Apple シリコン）用の翻訳サーバー |

## 1. Chrome 拡張を入れる

1. この zip を展開し、展開したフォルダを消えない場所（ドキュメントなど）に置きます。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension` フォルダを選びます。

使い方は `extension/README.md` を見てください。テキストを選択して「訳」ボタンを押すと翻訳できます。

## 2. 翻訳サーバーを起動する（任意）

翻訳サーバーを起動しておくと、拡張は自動でそちらを使います。ブラウザ内で翻訳するより約2倍速く、より大きいモデル（2B）で訳すので品質も上がります。

最初に1回だけ、下の手順で翻訳サーバーを起動してください。このとき、Chrome 拡張から翻訳サーバーを起動・停止できるように自動で登録されます。2回目以降は、拡張から操作できます（「3. 拡張から起動・停止する」）。

### Windows

1. `server-windows` フォルダの `PLaMoTranslateServer.exe` をダブルクリックします。
2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」を押してから「実行」を押します。
3. 初回だけ、翻訳モデル（約1.8GB）の最新版を公式の Hugging Face からダウンロードします。
4. 「起動しました」と表示されたら準備完了です。ウインドウは開いたままにしておきます。

### Mac（Apple シリコン）

1. `server-mac` フォルダの `start-server.command` を、右クリック（または Control キーを押しながらクリック）して「開く」を選びます。
2. 確認のメッセージが出たら「開く」を押します。ターミナルが開きます。
3. 初回だけ、翻訳モデル（約1.8GB）の最新版を公式の Hugging Face からダウンロードします。
4. 「起動しました」と表示されたら準備完了です。ターミナルは開いたままにしておきます。

### 止めるとき

ウインドウ（ターミナル）を閉じるか、`Ctrl+C` を押します。止めている間は、拡張がブラウザ内での翻訳に切り替わります。

## 3. 拡張から起動・停止する

一度起動して登録したあとは、ウインドウを開かずに拡張から操作できます。

- **右クリックメニュー**: ページの右クリックメニューの「翻訳サーバーを起動」「翻訳サーバーを停止」。進み具合はページの左下に表示されます。
- **設定画面**: 「翻訳サーバー（高速化）」の「起動」「停止」ボタン。
- **自動で起動**: 設定画面で「翻訳するときに自動で起動する」をオンにすると、翻訳を始めた時点で起動します。起動するまでの間はブラウザ内で翻訳します。

拡張から起動した翻訳サーバーは画面に出ずに動き、Chrome を終了すると止まります。

### 翻訳モデルの更新

翻訳モデルは公開元で更新されることがあります。ダウンロード済みのモデルはそのまま使い続け、新しい版が出ていれば次のどちらかで知らせます。

- `PLaMoTranslateServer.exe`（Mac は `start-server.command`）で起動したとき: 更新するか尋ねます。`y` で更新し、15秒たつか `n` で今の版のまま起動します。
- 拡張の設定画面: 「翻訳モデルの新しい版があります」と「更新」ボタンが出ます。

更新では、新しい版をダウンロードして確認し、起動できることを確かめてから差し替えます。新しい版で起動できなかったときは元の版に戻します。フォルダを移動したときは、もう一度 `PLaMoTranslateServer.exe`（Mac は `start-server.command`）を実行して登録し直してください。

## 動作環境

- Google Chrome 124 以降
- 翻訳サーバー: Windows 10 / 11（64ビット）、または Apple シリコンの Mac。空き容量 2GB 以上
- Windows は、Vulkan に対応した GPU（NVIDIA・AMD・Intel）があれば GPU で動きます。ない場合は CPU で動くため、速さはブラウザ内での翻訳と同じくらいです。

## 困ったとき

- **起動しない**: `server-windows/logs/server.log`（Mac は `server-mac/logs/server.log`）にエラーが記録されています。
- **「すでに起動しています」と出る**: 翻訳サーバーがすでに動いています。そのまま使えます。
- **拡張が翻訳サーバーを使わない**: 拡張の設定（ツールバーの拡張アイコン）で、翻訳エンジンが「自動」になっているか確認してください。
- **拡張から起動できない（「登録されていません」と出る）**: `PLaMoTranslateServer.exe`（Mac は `start-server.command`）を1回実行してください。会社の管理ポリシーで Chrome のネイティブメッセージングが禁止されている場合は、拡張からは起動できません。ウインドウから起動して使ってください。
- **ウイルス対策ソフトに止められる**: 署名のないプログラムのため、誤って検出されることがあります。

## アンインストール

拡張は `chrome://extensions` で削除します。翻訳サーバーは展開したフォルダごと削除します（ダウンロードしたモデルもフォルダ内の `models` に入っています）。

拡張から起動するための登録も消す場合:

- Windows: レジストリの `HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts\jp.plamo_translate.server`（Edge は `...\Microsoft\Edge\NativeMessagingHosts\...`）を削除します。
- Mac: `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/jp.plamo_translate.server.json` を削除します。
